How to check a QR code link before you open it

A QR code is just text you cannot read with your eyes. Before you act on it, read the full link: the scheme, the real domain and what it asks you to do. This page gives a short checklist, the warning signs of a fake code, and how to set up QR Code Halo so it shows you the content first instead of opening it right away.

A 30-second checklist for any QR code

  1. Look at the physical code. Is it a sticker on top of a printed code, on a parking meter, a charger or a poster? Stickers are an easy way to swap a real code for a fake one.
  2. Read the domain, not the page. The part right before the first single slash is the site you are going to. A look-alike spelling or an unrelated domain is a reason to stop.
  3. Check the scheme. A normal web link starts with https. Codes starting with javascript:, data: or file: are not ordinary links.
  4. Ask what it wants. A menu should not ask for your bank login. A parking payment should be in the city's own app or site.
  5. When in doubt, type the address yourself instead of following the code.

Set up QR Code Halo to check first

By default QR Code Halo acts the moment it reads a code: links open in your browser, Wi-Fi codes bring up the iOS Join prompt, and calls, messages, email and places open in their own apps. Contacts and events open the iOS add screen for you to confirm, and javascript:, data: or file: codes are never opened.

If you want to check every code before anything happens:

  1. Open Settings in QR Code Halo and turn off Run action after scanning.
  2. Scan with the camera, or choose a photo that contains the code.
  3. Open the scan in History and tap Security Check.

What the Security Check shows

ToolWhat it does
Local Payload Security InspectorParses the complete payload on the device into scheme, host, path, query and fragment, and returns Safe, Caution or Blocked with the findings behind it
QR VerificationSaves a result as a local reference, then compares a later scan by its full SHA-256 fingerprint, format, content type, URL parts and security level
Batch Risk & Difference AuditGroups exact duplicates and hosts across a batch and checks look-alike hosts within set limits

The rules are fixed and repeatable. There is no online reputation lookup and no fuzzy score; if parsing is uncertain, the action stays closed. QR Verification is handy for codes you see again, such as a shop's payment code: if a later scan does not match the saved fingerprint, the code has changed.

Frequently asked questions

How can I see where a QR code goes without opening it?

In QR Code Halo, turn off Run action after scanning in Settings. Scans are then saved without acting, and you can read the full content and run a Security Check in History.

Does the Security Check send my scans to a server?

No. It parses the content on your device with fixed rules and does not do an online reputation lookup.

Will it open a javascript: or data: code?

No. javascript:, data: and file: codes are never opened.

Can it scan a QR code from a screenshot?

Yes. Choose a photo and it recognizes the codes in it, even several in one image.

Can I make a Wi-Fi QR code for guests?

Yes. The Wi-Fi creator is one of the nine QR creators included without a purchase.

Is there a subscription?

No. The optional upgrade is a single one-time purchase.

QR Code Halo is an independent app and is not affiliated with Apple. The Security Check reads the code's content on your device with fixed rules; it does not look up a site's reputation online, so always use your own judgement before entering passwords or payment details.
