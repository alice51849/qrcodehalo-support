QR Code 連結檢查：掃描後先看清楚再開

QR Code 其實就是一串眼睛看不懂的文字。動作之前，先把完整內容讀出來：開頭的類型、真正的網域，以及它要你做什麼。本頁整理 30 秒檢查清單、假 QR Code 的常見特徵，以及怎麼把 QR Code Halo 設定成先顯示內容、不直接開啟。

  • 任何 QR Code 都適用的 30 秒檢查

任何 QR Code 都適用的 30 秒檢查

  1. 先看實體條碼。停車繳費機、充電站、海報上的條碼，是不是另外貼上去的貼紙？貼紙很容易把真的條碼換成假的。
  2. 看網域，不要只看頁面。網址裡第一個單斜線前面那段才是你要去的網站；拼字很像但不一樣、或跟店家無關的網域，就先停下來。
  3. 看開頭。一般網址是 https 開頭；javascript:、data:、file: 開頭的都不是普通連結。
  4. 想想它要你做什麼。餐廳菜單不需要你登入網銀；繳停車費應該在政府或業者自己的 App 或網站。
  5. 不確定就自己輸入網址，不要跟著條碼走。

把 QR Code Halo 設定成先檢查

QR Code Halo 預設是掃到就直接執行：網址用瀏覽器開啟、Wi-Fi 碼跳出 iOS 加入網路提示，電話、簡訊、Email 與地點交給各自的 App；聯絡人和行程會開啟 iOS 的新增畫面，由你確認後才加入；javascript:、data:、file: 這類內容一律不開啟。

想每一個都先檢查再決定：

  1. 在 QR Code Halo 的設定裡關閉「掃描後自動執行」。
  2. 用相機掃描，或選一張含有條碼的照片。
  3. 到歷史紀錄點開那一筆，按「安全檢查」。

安全檢查會顯示什麼

工具做什麼
Local Payload Security Inspector在裝置端解析完整內容，逐項顯示 scheme、host、path、query 與 fragment，並給出 Safe、Caution 或 Blocked 與判定依據
QR Verification把結果存成本機參照，之後再掃同一個條碼時，依完整 SHA-256 指紋、格式、內容類型、網址組成與安全層級比對
Batch Risk & Difference Audit把整批結果依完全相同內容與 host 分組，在明確界線內比較容易混淆的相似 host

判定規則固定且可重現，不查詢網路信譽，也不產生含糊分數；解析不確定時會阻擋外部操作。QR Verification 適合常掃的條碼，例如店家的付款碼：之後掃到的指紋跟存下來的不同，就代表條碼被換過。

同時也是完整的 QR Code 讀取與產生器

  • 讀取 20 種條碼格式，包含 QR、Micro QR、Aztec、Data Matrix、PDF417、EAN-13、UPC-A、Code 128。
  • 可辨識照片裡的條碼，同一畫面可同時讀多個，支援變焦與手電筒。
  • 產生文字、連結、Wi-Fi、聯絡人、電子郵件、電話、簡訊、位置與行事曆行程 QR Code。
  • 歷史紀錄不限筆數，有我的最愛、搜尋、篩選與 CSV 匯出；隱私模式會自動清除。

每台裝置可成功掃描 3 次，失敗或取消不算；9 種 QR Code 產生、不限筆數的歷史紀錄與完整稽核閱讀都不用購買。可選購的一次買斷（沒有訂閱）增加無限次掃描、批次、備份還原與高解析度匯出等功能。QR Code Halo 不是文件掃描器，不做 OCR。

常見問題

怎麼在不開啟的情況下看 QR Code 連到哪裡？

在 QR Code Halo 設定裡關閉「掃描後自動執行」，掃描後只會存下不執行，再到歷史紀錄看完整內容並做安全檢查。

安全檢查會把我的掃描內容傳到伺服器嗎？

不會。它在你的裝置上用固定規則解析內容，不上網查詢網站信譽。

javascript: 或 data: 開頭的條碼會被打開嗎？

不會。javascript:、data:、file: 這類內容一律不開啟。

可以讀取截圖裡的 QR Code 嗎？

可以。選擇照片就能辨識，同一張圖有好幾個條碼也能一起讀。

可以做給客人掃的 Wi-Fi QR Code 嗎？

可以。Wi-Fi 是不用購買就能用的 9 種 QR Code 之一。

需要訂閱嗎？

不需要。可選購的升級是一次買斷。

QR Code Halo 是獨立開發的 App，與 Apple 無關。安全檢查是在你的裝置上用固定規則解析條碼內容，不會上網查詢網站信譽；輸入密碼或付款資料前，請仍自行確認。
